# oakoss (personal OSS umbrella)

`oakoss` is the user's personal umbrella org for ALL their open-source work — a namespace for everything, not a single product or design-system brand.

- New OSS projects start as `oakoss/<name>`, with an optional npm scope under oakoss.
- A project breaks out into its own org or brand only once it outgrows the umbrella (its own community or identity). Let evidence trigger that; don't set up separate infrastructure upfront.
